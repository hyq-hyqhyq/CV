# 资产采集指南

本文档用于帮助完成真实物体 A、多视角背景和单图物体 C 的数据准备。

## 真实物体 A 怎么拍

1. 建议拍摄 80-150 张照片，或者拍摄一段稳定视频后用脚本抽帧。
2. 围绕物体完整转一圈，尽量覆盖 360 度视角。
3. 拍摄低、中、高三个高度，避免只有水平视角。
4. 物体尽量放在有纹理的桌面或背景前，方便 COLMAP 匹配特征。
5. 光照要均匀，不要频繁变化，避免强阴影、强反光和运动模糊。
6. 每张图中物体应尽量完整出现，不要大面积裁切。
7. 手机相机尽量锁定曝光和焦距，避免自动变焦导致内参变化太大。

## 物体 C 怎么拍

1. 使用单张清晰照片，物体完整、居中、无遮挡。
2. 背景尽量纯净，方便去背景工具得到干净 foreground PNG。
3. 使用较高分辨率，尽量保留纹理细节。
4. 光照要均匀，避免一侧过曝或背光。
5. 若物体有明显正面和背面，优先拍摄最能表达形状的视角。

## 哪些物体不要选

- 透明玻璃、水杯、亚克力等透明或半透明物体。
- 镜面金属、强反光塑料、亮面黑色物体。
- 极薄物体，例如纸片、细线、透明包装袋。
- 形状高度重复且缺少纹理的物体，例如纯白球、纯色圆柱。
- 会移动、变形或发光的物体。

## 如何保证 COLMAP 更容易成功

1. 相邻图片重叠率保持在 60% 以上。
2. 保持拍摄路径连续，不要突然跳视角。
3. 避免纯色背景，适当保留桌面纹理或背景纹理。
4. 如果物体本身纹理少，可以在旁边放一些不会遮挡物体的辅助纹理物。
5. 视频抽帧时不要抽得太稀，先用 `--stride 3` 或 `--stride 5` 试验。
6. 检查 COLMAP sparse 模型中注册图片数量，注册率太低时重新抽帧或补拍。

## 如何去背景

可使用 remove.bg、Photoshop、Segment Anything、RMBG、MODNet 或其他抠图工具。输出建议为 PNG 格式，保留 alpha 通道，文件放到：

```text
data/object_c/foreground_png/object_c.png
```

检查 foreground PNG 时需要确认：

- 背景为透明 alpha，不是白底或黑底假透明。
- 物体边缘没有大面积残留背景。
- 物体没有被误删关键部位。
- 图像四周留出少量空白，避免生成时边界被裁切。

## 如何检查重建结果是否可用

1. COLMAP 阶段：确认注册图片数量足够，稀疏点云覆盖物体区域。
2. 2DGS 阶段：查看训练预览图，确认物体轮廓稳定、主要纹理可见。
3. Mesh 导出阶段：用 Blender 或 MeshLab 打开 mesh，检查是否有大洞、漂浮点、严重噪声。
4. 归一化阶段：运行 `normalize_meshes.py` 后检查 `normalization_info.json`，确认 bbox 尺寸合理。
5. 融合阶段：打开 Blender preview，确认物体不穿模、不漂浮、尺度接近真实关系。
